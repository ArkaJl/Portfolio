1. Система цифровой платформы оценки образовательных результатов на основе P2P (peer-to-peer) подхода

Основной функционал: видеодемонстрация.mp4

Основная идея

Проект представляет собой цифровую платформу, в которой реализована гибридная модель оценивания. Студенты не только сдают свои работы, но и анонимно проверяют работы друг друга (P2P). Преподаватель при этом выполняет контролирующую и модераторскую роль: управляет учебными сессиями, следит за качеством рецензий (с помощью системы штрафов) и выставляет итоговые оценки.

Ключевые возможности системы

  • Для студентов: подключение к учебным сессиям по уникальному ключу, загрузка своих работ, проверка работ других студентов (с выставлением оценки и написанием комментария), просмотр полученных рецензий.
  • Для преподавателей: создание и управление группами и сессиями, загрузка учебных материалов, запуск этапа взаимной проверки, автоматическое распределение работ (каждый студент проверяет 3 работы), просмотр аудита рецензий, наложение штрафов на некачественные проверки, выставление итоговых оценок и экспорт результатов в Excel.
  • Для администраторов: управление пользователями (создание, редактирование, удаление), управление группами и их составом, а также общие системные настройки.

Технологический стек

  • Клиентская часть: Кроссплатформенное десктопное приложение на Tauri с использованием React, TypeScript и Vite. Это обеспечивает низкое потребление ресурсов и малый размер приложения.
  • Серверная часть: NestJS (фреймворк для Node.js) с TypeScript. Для взаимодействия в реальном времени используется Socket.io.
  • База данных: PostgreSQL с Prisma ORM для типобезопасной работы с данными.
  • Развертывание: Docker и Docker Compose, с автоматизированным CI/CD-пайплайном на GitHub Actions.
  • Тестирование: Функциональное (Jest, Supertest), нагрузочное (k6) и юнит-тестирование.

Роли пользователей

  1. Студент: основной участник процесса оценивания.
  2. Преподаватель: организатор и модератор учебного процесса.
  3. Администратор: управляющий учетными записями и системными настройками.

Ключевые особенности

  • Автоматическое распределение работ: Используется алгоритм Фишера-Йетса для случайного и равномерного назначения рецензентов.
  • Система штрафов: Преподаватель может снизить итоговую оценку студента за некачественно выполненную рецензию.
  • Расчет итоговой оценки: Формула finalGrade = max(2, grade - penalty) гарантирует, что оценка не опустится ниже минимального балла.
  • Экспорт данных: Возможность выгрузки результатов сессии в формате Excel и создания ZIP-архивов с работами и материалами.
  • Управление жизненным циклом сессии: Сессия проходит через несколько статусов: WAITING, ACTIVE, REVIEWING, CLOSED, CANCELLED.

2. Приложение для интерактивного изучения английского языка с рейтинговой системой на основе аддитивного критерия

Ссылка на репозиторий: github.com/ArkaJl/CourseProject

Основной функционал: видеодемонстрация.mkv

Основная идея

Приложение представляет собой веб-платформу для изучения английского языка, сочетающую в себе элементы геймификации и социального взаимодействия. Пользователи (ученики) проходят курсы, состоящие из уроков и заданий, отслеживают свой прогресс и соревнуются в рейтинге. Преподаватели, в свою очередь, получают инструменты для создания собственного образовательного контента (курсов, уроков, заданий) и управления учебными классами.

Ключевые возможности системы

Для учеников (Student)

  • Регистрация и авторизация с выбором роли.
  • Просмотр каталога курсов, сгруппированных по категориям, и поиск по названию.
  • Прохождение курсов, состоящих из последовательных уроков с интерактивными заданиями (викторинами).
  • Просмотр личного профиля с историей пройденных уроков, количеством набранных баллов и датами выполнения.
  • Участие в общем рейтинге (таблице лидеров) для повышения мотивации.
  • Вступление в классы, созданные преподавателями, для доступа к их курсам.

Для преподавателей (Teacher)

  • Создание и управление собственными курсами, уроками и заданиями.
  • Добавление в уроки вопросов с несколькими вариантами ответов, указание правильного ответа и количества баллов за задание.
  • Создание учебных классов и управление ими (принятие или отклонение запросов на вступление).
  • Просмотр списка студентов в классе и их детального прогресса по курсам (какие уроки и с каким результатом пройдены).

Технологический стек

  • Клиентская часть (Frontend): React (с использованием функциональных компонентов и хуков, таких как useState, useEffect) для создания динамичного пользовательского интерфейса. Для взаимодействия с сервером используется библиотека Axios.
  • Серверная часть (Backend): Node.js с фреймворком Express.js для обработки HTTP-запросов и реализации REST API.
  • База данных: MySQL (реляционная СУБД) для хранения данных о пользователях, курсах, уроках, заданиях и результатах.

Роли пользователей

  1. Ученик (Student): основной потребитель контента, проходящий курсы и выполняющий задания.
  2. Преподаватель (Teacher): создатель контента и управляющий учебными классами.

Ключевые особенности и алгоритмы

  • Валидация данных: Проверка корректности ввода на стороне клиента (email, длина пароля) и сервера.
  • Последовательное прохождение уроков: Уроки в курсе упорядочены, и система отслеживает, какие из них уже пройдены.
  • Система начисления баллов: За каждое правильно выполненное задание начисляются баллы, которые суммируются и влияют на позицию в рейтинге.
  • Каскадное удаление: При удалении курса автоматически удаляются все связанные с ним уроки и задания.
  • Таблица лидеров: Реализован алгоритм для отображения топ-3 пользователей и позиции текущего пользователя с его ближайшим окружением.
